# Photography Client Gallery

A full-stack photography platform for showcasing a photographer’s work through public portfolio pages and a client-focused gallery experience.

## Overview

This project is being developed as a real-world client-facing website for a photographer. The goal is to create a polished portfolio and private gallery experience where clients can view their photos through a clean, responsive interface.

## Tech Stack

- React
- TypeScript
- Node.js
- Express
- MongoDB
- Cloudinary

## Planned / In Progress Features

- Public portfolio pages
- Responsive gallery layouts
- Client gallery viewing experience
- Authentication and protected routes
- Client-specific private gallery access
- Cloudinary image storage and delivery

## Current Status

This project is currently being rebuilt and refined. The main focus is creating a polished frontend experience first, then expanding the authentication and private gallery functionality.

## Project Goals

- Build a professional client-facing photography platform
- Practice full-stack development with authentication, media storage, and protected routes
- Create a reusable project structure for future freelance/client websites# Photography Client Gallery
